### En lo que ando

🍝 **[ReservasIlCapo](https://github.com/JokinBAnza/ReservasIlCapo)** — Sistema de reservas para el
restaurante donde trabajo: web pública, panel de sala y mapa de mesas. **Laravel + Docker + MySQL.**
Lo estamos probando con clientes reales, que es donde se aprende lo que ningún tutorial cuenta.

🏊 **[ReservasPiscinaIrun](https://github.com/JokinBAnza/ReservasPiscinaIrun)** — Bot que cada noche
reserva plaza en la piscina municipal. Sin navegador: **HTTP directo tras hacer ingeniería inversa
del formulario**, con concurrencia, control de sanciones y avisos por Telegram. **Python, sin
dependencias externas.** Lleva funcionando solo toda la temporada.

🎯 **[LINGO](https://github.com/JokinBAnza/LINGO)** — Juego de palabras tipo Wordle con registro,
login y puntuaciones. **Laravel + Docker**, con despliegue por GitHub Actions.

Fuera de GitHub también tengo un bot de trading en Python (Telegram + un LLM para el análisis) que
llegó a operar con dinero real, y la casa automatizada con Home Assistant.
